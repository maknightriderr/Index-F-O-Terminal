## Shared mathematical correction

Independent price validation exposed a pre-existing normal-CDF bug. The coefficients in `greeks/index.ts` approximate erf, but the polynomial used x rather than x/√2 while its exponential used exp(-x²/2). Correct both terms to the erf argument: Φ(x) = (1 + erf(x/√2))/2. See [NIST DLMF 7.1](https://dlmf.nist.gov/7.1) and [7.20](https://dlmf.nist.gov/7.20).

Three independent benchmark tests use standard normal-table values, the density derivative, and reference prices computed with Python's `math.erf`, rather than option prices generated by the implementation under test. S=K=100, T=1, r=5%, σ=20% has call value 10.4505835722 and put 5.5735260223. A zero-rate S=K=6000, T=15/365, σ=9% call is 43.671388415. IV/delta recovery also uses independent references.

This correction affects newly computed model prices, IV and Greeks wherever the shared helper is used. It does not rewrite actual quotes, ledger P&L, historical records, original-risk snapshots or held exit policies. New pricing evidence records `normalCdf: ERF_SQRT2_FIXED_V1` so subsequent model observations can be distinguished. Do not combine old/new model evidence into a claim of validated strategy edge, and do not reset account counters merely to change model labels.

## Implemented engineering

Current master option expiries must resolve uniquely to the signal future via the previously verified contract rules. A nearest-month, spot index or foreign-exchange reference cannot replace it. The production adapter uses MCX session/expiry windows and exact option identifiers. It freezes the option/future linkage, sizing, fee and model evidence in the contract.

Calibration fixes F to the observed exact future, and fits only D in C-P=D(F-K), requiring three to five fresh same-source/epoch strike pairs whose parity lies inside quoted bid/ask bounds. It rejects duplicate quote identities, inconsistent future marks, stale/future-dated observations and mismatched timestamps. Scenario repricing moves that same future directly to structural target/stop levels, without an inferred cash/forward ratio. Selected option books independently pass freshness/quantity checks.

The adapter uses independently verified broker quantities and premium multipliers, CTT-aware MCX fees, and the same transactionally reserved account risk as other markets. Default raw MCX master quantities remain unverified. Discovery removes the unit blocker only if an exact-linked option independently passes verified-unit metadata; large raw depth and mere master membership cannot qualify it. Quantity checks run before linkage scans to keep raw-master discovery bounded.

Pure admission accepts the explicit MCX policy marker only with its expiry/spread and all existing capability/risk gates. Missing approval, commodity event coverage or quantity verification blocks production. The actual event-source implementation still returns `BLOCKED_COMMODITY_EVENT_COVERAGE`; tests never relabel that as real coverage.
