# F&O Market Radar

Adds breadth and two directional watchlists above the existing F&O Explorer views. Counts come from the NSE instrument-master universe joined to the newest row per symbol; missing/invalid and in-session stale rows are separate from neutral. Table filters do not affect breadth. Unknown universe gives unknown total/missing counts. Outside session, clearly labelled last-known observations are retained. Successful empty scans clear previous rows.

Candidates require directional scanner bias, matching relative strength against NIFTY and finite recorded ATM average spread within the existing shared liquidity threshold. Bullish sorts score descending; bearish sorts ascending because scanner score is `50 + net * 45`. Relative strength and symbol break ties. Up to ten candidates, never padded. These are screening watchlists, not entry-ready recommendations: scanner snapshots do not contain triggers, stop/target geometry or distance to obstacles. Those are not fabricated. Breadth change compares consecutive observed snapshots during this mounted visit, not previous-session persisted history.

Stock clicks open the existing workspace with a prominent InstrumentChart and closed-candle OB/FVG overlays. Exact cash-equity token lookup supports stock spot charts; futures history now explicitly sends segment FO while spot sends CM. Existing chart reset/error/zone lifecycle behavior is reused. No algorithm, broker execution, strategy entry/exit, sizing, backend or database changes.

The options panel selects strike and CE/PE from the workspace's selected-expiry chain and exposes per-contract IV, Greeks, spread, bid/ask, volume/OI and quote timestamps. A hypothetical 1/2/5 percentage-point IV decline uses local vega, capped at premium. This is first-order per-share sensitivity, not predicted IV crush; no invented earnings date, historical IV percentile, execution cost or missing quote. The existing expiry selector, setup/SR panels, option chain and corporate-action calendar remain available. A missing option chain explicitly shows unavailable.

Validation: 147 frontend tests, TypeScript, production build and targeted lint. New tests cover universe partition, duplicate/stale/invalid rows, missing denominator, empty scans, non-padded top ten, both directional ranking orders, exact cash token resolution, CE/PE sensitivity and missing contract/IV. Chromium fixture QA covers dark/light Radar, 1440px/390px widths, accessibility of Radar, both shortlist directions, opening a stock chart, rendered OB/FVG and explicit CM/FO history requests. No browser exceptions or write requests. Browser populated options-risk scenarios are covered by component tests; browser workspace uses missing-chain state. Screenshots inspected locally, not published. This is not an authenticated production market-data audit.
